## 記載の対象外としたもの

第三者の著作物ではないため、上の表に含めない。

- UI のアイコン（`src/components/icon.tsx` の SVG）と、構成図の端末アイコン：自作の図形。
- デモ用の講義カテゴリと公開Q&A（`scripts/seed-demo.ts`）：自作の文章。
- Gemini の評価用50問（`docs/hackathon/gemini-eval-cases.json`）：架空の合成データ。
- Google ログインボタン：文字だけで、Google のロゴ画像は使っていない。
- CSS の `font-family` で指定している Noto Sans JP：フォントを同梱・配信しておらず、閲覧者の端末にあれば使われるだけ。
